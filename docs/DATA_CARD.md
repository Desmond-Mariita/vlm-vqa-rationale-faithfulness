# Data card

The experimental dataset is VCR, acquired externally under its terms. The public candidate contains schemas, numeric scores/counts, hashes, wholly synthetic examples, and limited thesis-contained source excerpts/figure dependencies. It is not a VCR dataset redistribution.

Numeric projections contain arm/condition labels, integer record/frame codes, predictions/counts, text hashes and frozen scores. They contain no questions, choices, rationale text, descriptions or image bytes. Shared coding preserves pair/cluster relationships; no inverse ID mapping is supplied. Projection lineage and hashes are in provenance/numeric_projection.json.

The synthetic example depicts simple geometric objects and is authored for this release; it is not a movie frame or a VCR record. All original and derived image corpora, captions, raw generation text and annotations remain external.
